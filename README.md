# 身份证扫描件生成器

一个功能强大的桌面应用程序，用于将身份证正反面图片合成为标准A4格式的PDF扫描件。

## 功能特点

- ✅ **图片上传**：支持多种图片格式（JPG、PNG、BMP等）
- ✅ **自动校正**：智能检测身份证边缘，自动进行透视校正
- ✅ **手动校正**：支持手动点击四个角点进行精确校正
- ✅ **背景消除**：自动去除背景，保留身份证主体
- ✅ **形变校正**：透视变换消除拍摄角度造成的形变
- ✅ **A4排版**：自动将正反面合成到A4纸上
- ✅ **PDF导出**：生成高质量PDF文件（300 DPI）
- ✅ **友好界面**：直观的图形用户界面，操作简单

## 使用方法

### 运行程序

```bash
python main.py
```

### 操作步骤

1. **上传正面图片**
   - 点击"上传正面"按钮
   - 选择身份证正面照片

2. **校正正面图片**
   - 方式一：点击"自动校正"，程序自动检测边缘
   - 方式二：手动点击图片的四个角点（按顺序：左上、右上、右下、左下）
   - 如需重新选择，点击"清除角点"

3. **上传反面图片**
   - 点击"上传反面"按钮
   - 选择身份证反面照片

4. **校正反面图片**
   - 重复步骤2的操作

5. **生成PDF**
   - 点击"生成扫描件"按钮
   - 选择保存位置和文件名
   - 等待处理完成

## 使用技巧

### 拍摄建议

- 在光线充足的环境下拍摄
- 尽量保持身份证平整
- 拍摄角度尽量垂直
- 确保身份证边缘清晰可见
- 背景尽量简洁，与身份证颜色有对比

### 校正技巧

- 如果自动校正不准确，可以使用手动校正
- 手动点击角点时，尽量贴近身份证的实际角点
- 四个角点的顺序为：左上、右上、右下、左下

## 打包为可执行文件

### 安装PyInstaller

```bash
pip install pyinstaller
```

### 打包命令

```bash
python build_exe.py
```

> 注意：请使用 `build_exe.py` 打包，不要直接调用 `pyinstaller` 命令。
> 脚本内置了两个关键修复（详见 `build_exe.py` 内注释）：
> 1. 依赖扫描与启动时强制 onnxruntime/rembg 先于 PyQt5 加载（否则 DLL 加载顺序冲突导致段错误）
> 2. 打包 pymatting 等包的版本元数据（缺失会导致启动时报 `PackageNotFoundError`）
>
> 如需离线使用背景消除功能，打包前把 `u2net.onnx` 放到 `models/u2net/` 目录（约 176MB，
> 首次使用 rembg 时也会自动下载到 `~/.rembg/models/u2net/`），脚本会将其内置到 exe 中。

打包完成后，可执行文件位于 `dist` 目录下。单文件 exe 可直接拷贝到任意 x86_64 的
Windows 10/11 机器运行（无需安装 Python）；因未签名，首次运行需在 SmartScreen
提示中选择「更多信息 → 仍要运行」。

## 故障排除

### 问题：无法检测到身份证边缘

**解决方案**：
- 确保图片清晰，光线充足
- 尝试手动点击四个角点进行校正
- 检查图片背景是否过于复杂

### 问题：生成的PDF质量不佳

**解决方案**：
- 使用更高分辨率的原始图片
- 确保拍摄时对焦清晰
- 避免使用过度压缩的图片

### 问题：程序无法启动

**解决方案**：
- 检查Python版本是否正确
- 确认所有依赖已正确安装
- 尝试重新安装依赖：`pip install -r requirements.txt --force-reinstall`

- 新增：`build_exe.py` 一键打包为单文件 exe（含启动预加载钩子 `rthook_preload.py`、元数据收集、离线模型内置）
